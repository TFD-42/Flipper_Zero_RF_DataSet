# Ethics & Legal Usage Statement – RF Dataset
**Version**: 1.0  
**Last Updated**: 2026-06-15  
**Applies to**: Flipper_Zero_RF_DataSet (RF Sub‑GHz dataset for LLM fine‑tuning)  
**Binding**: Use of this dataset constitutes acceptance of all terms below.

## 1. Permitted Uses
- **Academic research** on RF spectrum analysis, signal classification, and machine learning.
- **Educational projects** teaching RF fundamentals and LLM applications.
- **Authorized security testing** with explicit permission from device owners.
- **Development of defensive RF monitoring tools**.

## 2. Prohibited Uses
- **Mass surveillance** – using the dataset to train models for large‑scale, unauthorised monitoring.
- **Jamming or interference** – developing tools that disrupt legitimate RF communications.
- **Tracking individuals** without consent.
- **Military or law enforcement targeting** without strict legal oversight.
- **Any illegal activity** violating local telecoms, privacy, or computer misuse laws.

## 3. Data Origin & Privacy
The dataset contains only synthetic or publicly available RF signatures.  
No personally identifiable information (PII) is included.  
If you believe any data violates privacy, please report via GitHub private security advisory.

## 4. User Responsibility
You are solely responsible for ensuring your use complies with all applicable laws.  
The dataset authors assume no liability for misuse or model outputs.

## 5. Reporting Violations
Use GitHub’s **private security advisory** (Settings → Security → Advisories) to report suspected unethical use.

## 6. Changes
This statement may be updated. Continued use implies acceptance.
